This ranking is **implementation-first**. README quality, repository names, stars, and visual polish do not determine technical rank.

## Ranking criteria

1. implementation/architecture depth
2. real product or operational value
3. systems/realtime/data complexity
4. completeness
5. collaboration and ownership evidence
6. presentation quality last

# Canonical public story

A recruiter should not need to inspect sixty repositories to understand the profile. The main account should tell six distinct engineering stories:

1. **MINA GAMES / `minapong/ft_transcendence`** — team collaboration + realtime architecture
2. **`real_estate_management`** — product/business application engineering
3. **`IRC`** — networking + non-blocking C++ systems work
4. **`secret-hitler`** — realtime state machine + multiplayer backend
5. **`Customer_service_agent`** — API integration + workflow automation
6. **`Audify`** — AI-enabled full-stack product

Supporting depth then comes from `42curcus`, `MINISHELLING`, `Code-Smith`, `Twitter_clone`, `philo`, `tourism_app`, and `cv_portfolio`.

## Recommended six pins

```text
minapong/ft_transcendence
iamhashir/real_estate_management
iamhashir/IRC
iamhashir/secret-hitler
iamhashir/Customer_service_agent
iamhashir/Audify
```

If GitHub does not offer the organization repository in **Customize your pins**, use `42curcus` as the replacement and link MINA GAMES prominently from the profile README.
